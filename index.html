Projects

01

Rating Prediction Model for Google Maps Reviews

Python scikit-learn Pandas

Built a machine learning model to predict user ratings on 20,000+ Google Maps reviews, engineering a hybrid feature set that combined TF-IDF text analysis, collaborative filtering, and behavioral signals. Was able to improve prediction accuracy by 17.5% over baseline by combining logistic regression with class balancing, reaching 68.7% accuracy and 0.48 MAE. We validated model performance with a time-series train/test split and evaluated results using accuracy, F1-score, MAE, and confusion matrices.
